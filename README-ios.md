# Курсы валют — iPhone

Та же программа, что и Android-версия: курсы доллара, российского и белорусского
рублей, курсы обменников отделений банков, ближайшие обменники и виджет
на рабочем столе.

Эти исходники лежат в каталоге `ios/` монорепозитория
(`yur7yur7yur7/kursy-valut-source`), где лежит и общая инструкция по сборке
Android и iOS. Этот же каталог — публичное зеркало `kursy-valut-ios`: там
собирается `.ipa` в GitHub Actions, потому что macOS-раннеры бесплатны только
для публичных репозиториев.

## Скачать

**Готовая сборка (неподписанный .ipa):**
https://github.com/yur7yur7yur7/kursy-valut-ios/releases/download/ios-v1.1.0/RatesApp-unsigned.ipa

Файл ставится через Sideloadly — подпись Apple ID ставится при установке
(инструкция ниже). Требуется iOS 16.0 или новее.

## Что внутри

- **Вкладка «Курсы»** — два конвертера (Яндекс и myfin.by). Сумма общая для
  обоих блоков: правите одну строку — пересчитываются остальные.
- **Вкладка «Обменники»** — лучший курс по городу (снимок всех 22 банков) и
  закреплённые отделения. Если ваш курс ниже лучшего, приложение покажет
  плашку «↓ ниже лучшего на 0,014 ₽ · на 100 $ это 1,40 ₽».
- **Вкладка «Рядом»** — ближайшие отделения в радиусе 2 км: логотип, тип
  (отделение, обменный пункт, ЦБУ), адрес, расстояние и курс. Сумма в долларах
  одна на весь список, пересчёт сразу во всех карточках.
- **Сортировка вкладки «Рядом»** — переключатель «По дальности» (по умолчанию)
  или «По курсу», от большего к меньшему.
- **Если местоположение выключено на устройстве** — приложение не запускает
  поиск, а предлагает его включить. Если отказаться, во вкладке останется
  пометка, что геолокация выключена.
- **Виджет** — официальный курс и лучший курс по городу прямо на рабочем столе.
- **«Поделиться»** и **«В картах»** — отправить курс в мессенджер или открыть
  отделение в Apple Maps.

Координаты отделений берутся из снимка kurs.onliner.by — там они есть у всех
479 отделений, поэтому геокодер не нужен.

## Сборка без Mac

Сборка идёт в облаке, вам нужен только компьютер с Windows и Apple ID.

### Вариант 1 — GitHub Actions

1. Откройте **Actions** → **Build iOS (unsigned .ipa)** → **Run workflow**.
2. Скачайте артефакт `RatesApp-unsigned-ipa` (файл `RatesApp-unsigned.ipa`).

macOS-раннеры GitHub не всегда доступны сразу — если сборка висит в статусе
«queued» дольше 10 минут, переходите к варианту 2.

Для публичных репозиториев macOS-раннеры бесплатные, для приватных — нет.
Поэтому сборка iOS идёт в публичном зеркале `kursy-valut-ios`.

### Вариант 2 — Codemagic (надёжнее, если GitHub не выдаёт macOS-раннер)

1. Зарегистрируйтесь на [codemagic.io](https://codemagic.io) (email + пароль).
2. В Codemagic нажмите **Add new application** → **GitHub** → выберите репозиторий
   `kursy-valut-ios` (потребуется авторизовать Codemagic в GitHub).
3. Откройте приложение → вкладка **Build settings** → **Add app**:
   - Platform: **iOS**;
   - Bundle id: `ru.yur7.ratesapp`;
   - нажмите **Start build** (или вкладка **Build** → **Start new build**).
4. Сборка занимает ~5–10 минут. Когда она станет зелёной, откройте вкладку
   **Artifacts** и скачайте `RatesApp-unsigned.ipa`.
5. Ставите `.ipa` через Sideloadly (шаги ниже).

Конфиг `codemagic.yaml` уже в репозитории — свои настройки в Codemagic вводить
не нужно, только Bundle id для логов.

Если сборка ругнётся на версию Xcode, удалите в `codemagic.yaml` **весь блок
`macos:`** (он сейчас и не нужен — версия Xcode по умолчанию подходит) и
запустите сборку снова. Комментировать строки внутри блока нельзя: останется
пустой объект, и проверка схемы его отвергнет.

### Установка на iPhone

1. Установите [Sideloadly](https://sideloadly.io) на компьютере.
2. В Sideloadly: подключите iPhone по USB (на телефоне нажмите «Доверять» этому
   компьютеру) либо введите Apple ID и включите «Sideload via WiFi»;
   - поле **iTunes Path** — укажите `iTunes.exe` из установленного iTunes
     (нужно только для USB-варианта);
   - поле **IPA File** — выберите скачанный `.ipa`;
   - введите Apple ID и пароль, нажмите **Start**.
3. На iPhone: «Настройки» → «Основные» → «Объект VPN и управление устройством»
   → доверьте разработчика (если iOS попросит) → приложение появится на
   рабочем столе.

**Подпись живёт 7 дней.** Через неделю откройте Sideloadly и нажмите
**Refresh Apps** — приложение снова заработает. Чтобы не возиться раз в неделю,
поставьте [AltStore](https://altstore.io) или запустите Sideloadly по расписанию.

## Сборка на своём Mac

```bash
brew install xcodegen
xcodegen generate --spec project.yml
open RatesApp.xcodeproj
```

Дальше — обычная разработка под iPhone: выберите свой iPhone и нажмите Run
(для бесплатного Apple ID подпись тоже живёт 7 дней).

## Виджет

Виджет ставится вместе с приложением: долгий пресс по рабочему столу →
«+» → «Курсы валют». Виджет сам забирает данные из сети и кеширует их у себя,
поэтому работает и без открытого приложения.

Строка «Рядом: <банк> · <расстояние>» в виджете требует общей группы
приложений (App Group) — она доступна только с платным аккаунтом разработчика.
На бесплатном Apple ID виджет показывает курсы без расстояния.

## Структура

```
project.yml            описание проекта для XcodeGen
Sources/Shared/        общий код: модели, парсеры, сеть (и приложение, и виджет)
Sources/App/           приложение: экраны, оформление, кеш, геолокация
Sources/Widget/        виджет WidgetKit
tools/                 служебные проверки исходников
```

CI лежит в `.github/workflows/` — сборка `.ipa` и проверка синтаксиса Swift.
Те же файлы workflow работают и в монорепозитории, и в этом зеркале: каталог
с исходниками определяется на лету, поэтому правило одинаковое в обоих местах.

Проверка синтаксиса Swift работает на обычном Linux-раннере
(`swiftc -parse` по всем файлам) — это быстрый способ поймать опечатки
до полной сборки на macOS.

Данные приходят с тех же сайтов, что и в Android-версии: Яндекс, myfin.by
(НБ РБ и ЦБ РФ) и kurs.onliner.by. Данные носят справочный характер:
официальные курсы банков всегда уточняются в кассе.
